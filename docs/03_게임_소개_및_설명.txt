────────────────────────────────────────────────────────────────────────────────
1. 한 줄 소개
────────────────────────────────────────────────────────────────────────────────

  "실제 과거 주식 차트를 종목명을 가린 채 되감아 보여준다.
   당신의 매매 실력이 곧 방어 자금이 되고, 방어에 실패하면 사옥이 무너진다."

  실제 한국 증시의 과거 일봉 데이터를 블라인드로 리플레이하는 트레이딩과,
  그 수익으로 병력을 굴리는 일자형 타워디펜스를 하나의 루프로 묶은 하이브리드
  게임이다. 차트를 읽는 눈이 전투력으로 직결된다.


────────────────────────────────────────────────────────────────────────────────
2. 게임 개요
────────────────────────────────────────────────────────────────────────────────

■ 장르       실시간 트레이딩 × 타워디펜스 하이브리드 (싱글플레이, 웹)
■ 플레이 시간  1스테이지 약 6분 30초 (390거래일 × 1초)
■ 핵심 재미   ① 정체를 모르는 차트를 읽어내는 추리
              ② 번 돈을 언제 병력에 쓸지 결정하는 자원 배분
              ③ 클리어 후 "이게 무슨 종목이었는지" 밝혀지는 반전

■ 핵심 루프

    ┌─ 블라인드 차트 관측 (일봉 1개 = 게임 1초)
    │        ↓
    │  LONG / SHORT 진입 → 청산
    │        ↓
    │  실현 수익 → 골드 전환 (손실은 운용자금에서 차감)
    │        ↓
    │  골드로 유닛 소환 · 포탑 건설
    │        ↓
    │  13웨이브 방어 (또는 적 본진 파괴)
    │        ↓
    └─ 클리어 → 종목·기간 공개 → 도감 등록 → 다음 지역 해금

■ 두 가지 화폐

    AUM (운용자금)   트레이딩 원금. 포지션 투입에만 사용한다.
                     손실이 나면 여기서 깎이고, 바닥나면 파산 패배.
    골드             전투 자원. 유닛·포탑·스킬에만 사용한다.
                     트레이딩 실현 수익과 웨이브 기본 수입으로 들어온다.

    → 두 화폐가 분리돼 있어 "잘 벌면 강해지고, 잃으면 방어가 얇아지는"
      직접적인 인과가 만들어진다.

■ 진행 구조

    타이틀 → 튜토리얼 → 세계지도 → 국가(한국) → 지역 선택 → 스테이지
    → 정산 → 종목 공개 연출 → 도감 → 회사(부서 업그레이드) → 다음 지역

    지역 3곳 (난이도 순)
      R1 여의도 · 금융        박스권 차트가 자주 나와 실수에 관대
      R2 판교 · IT/플랫폼     변동성 중간
      R3 울산 · 중공업/에너지  원웨이·급변 차트 위주, 손실 계수가 가장 가혹


────────────────────────────────────────────────────────────────────────────────
3. 플레이 방법
────────────────────────────────────────────────────────────────────────────────

3-1. 트레이딩

  · 화면 상단에 종목명이 가려진 일봉 차트가 1초에 하루씩 흐른다.
    (총 390거래일 ≈ 1년 7개월치를 약 6분 30초 동안 관측)
  · LONG(상승 베팅) / SHORT(하락 베팅) 중 방향을 고르고, 투입 비중을
    10% / 25% / 50% / ALL 중에서 선택해 진입한다.
  · 원할 때 청산한다. 만기는 없다. 동시 보유는 1건.
  · 체결가는 "요청한 순간 화면에 보이는 가격"이다. 서버가 같은 보간식을
    재현해 검증하므로 클라이언트를 조작해도 이득이 없다.

  손익 계산
      g = 방향 × (가격변동% ÷ σ30) × 레버리지        (σ30 = 30거래일 변동성)
      수익률 = 0.9 × g   (손실 시에는 지역별 손실계수 L을 곱한다)
      L = R1 0.70 / R2 1.05 / R3 1.70
      → 어려운 지역일수록 틀렸을 때 더 크게 잃는다. 손익분기 승률이
        R1 40.5% / R2 45.4% / R3 50.2%가 되도록 실데이터로 역산해 정했다.

  레버리지 (1× / 2× / 3× / 5×)
      기본은 1×만 열려 있고, 회사 화면의 [마진 데스크] 부서를 올리면
      2·3×(Lv2), 5×(Lv3)가 해금된다.

  마진콜 (강제청산)
      미실현 손실이 투입금의 95%에 닿으면 서버가 즉시 전액 청산한다.
      이때는 원금이 전액 소멸하므로, ALL 투입 상태에서 마진콜을 맞으면
      그대로 파산 패배다. 포지션 패널에 "청산선"(몇 % 움직이면 터지는지)이
      항상 표시되고, 레버리지가 높을수록 청산선이 가까워진다.

  골드 전환
      청산 순수익은 1건당 최대 500G까지만 골드가 되고, 초과분은 AUM으로
      쌓인다. 한 방 대박으로 전투가 끝나버리지 않게 하되, 번 돈이 사라지지는
      않도록 한 장치다.

3-2. 전투

  · 전장은 좌우 일자형. 왼쪽이 아군 사옥, 오른쪽이 적 본진이다.
  · 30초 주기로 웨이브가 진행된다(준비 10초 + 교전 20초), 총 13웨이브.

  유닛 (9종 · 소환 즉시 자동 전진, 자동 교전)
      망치 견습공     35G   근접  빠른 회전의 저가 딜러
      가위 병사       60G   근접  단일 특화 (출혈 + 방어 감소)
      종머리 곤봉병   70G   근접  유일한 광역 기절원
      원형 방패병     80G   탱커  넉백으로 전선을 되돌린다
      벽돌 짐꾼       85G   탱커  광역 피해 + 둔화
      셔터 장교       90G   탱커  유일한 보호막 공급원 (기절·둔화 정화)
      방독면 포수     95G   원거리 독가스 — 적 힐러 무력화의 유일한 수단
      망치 작업반장  110G   탱커  광역 기절 + 공중 띄움
      저격수         120G   원거리 관통 사격 (방어 무시 50%)

  포탑 (3종 · 슬롯 3칸)
      지정가 포탑    165G   지상+공중 단일 저격, 최장 사거리
      옵션 스파이어  210G   마법 피해 + 이동 감속 30%
      공매도 캐논    225G   지상 광역 포격

      슬롯 배치가 특이하다 — 사옥을 위아래로 등분해 옥상·중층에 2칸,
      지면에 1칸이다. 포탑을 건물 위에 얹는 구조다.

  스킬 (전 유닛 자동)
      타이머가 아니라 "평타 N회를 친 뒤" 발동한다. 유닛은 교전 중에만
      평타를 치므로, 실제로 싸운 만큼만 스킬이 나간다. 판정은 스프라이트의
      타격 프레임에 정확히 들어간다.
      전역 스킬로 [공시폭탄](200G, 쿨 25초)이 있어 화면 전체를 타격한다.

  상태이상
      기절 · 넉백 · 공중 띄움 · 둔화 · 출혈 · 취약(방어 감소) ·
      표식(받는 피해 증가) · 회복 차단 · 보호막 · 정화
      기절은 끝난 뒤 3초간 재기절 면역이 걸려 스턴락이 불가능하다.

  적군 (7유형)
      창 망령(관통) · 석궁 사수(삼연사·둔화) · 다연장 포병(융단 포격) ·
      방패 파쇄병(보호막 파괴) · 확성기 드론(아군 버프) · 연 정찰기(공중·표식) ·
      번개 왕(보스·낙뢰 기절)
      적 본진 체력이 40%·20%를 깨질 때마다 정예 반격 분대가 투입되고,
      충격파가 아군을 전장 중앙까지 밀어낸다. (DANGER 경보)

3-3. 승리 / 패배

  승리   ① 13웨이브 전부 방어  또는  ② 적 본진 파괴 (즉시 승리)
  패배   ① 사옥 HP 0  ② 파산(AUM 소진)  ③ 이탈
  → 정산 화면에 승패 사유가 문장으로 표시된다.

3-4. 정산 · 성장

  등급 S/A/B/C = 아래 4개 항목의 점수 합 (최대 7점)
      운용 성과   원금 대비 +15% 이상 2점 / 원금 보전 1점
      적중률      65% 이상 2점 / 55% 이상 1점
      사옥 HP     90 이상 2점 / 70 이상 1점
      적 본진 파괴 1점

  · 등급과 성과에 따라 자본금을 받고, 자본금으로 회사 부서 6종을 올린다.
    (트레이딩 데스크 / R&D / 인사팀 / 법무팀 / IR팀 / 마진 데스크)
  · 지역을 점령하면 보상 계열 4종 중 1개만 고를 수 있다 — 나머지는 포기.
  · 클리어한 종목은 도감에 등록된다. 실패해도 정체는 공개된다.

4. 실행 방법
────────────────────────────────────────────────────────────────────────────────

■ 요구 사항
    Node.js 20 이상
    Python 3.10 이상 (차트 데이터 수집용)
    최신 크로미움 계열 브라우저

■ 설치 및 실행

    git clone https://github.com/cchriscode/StockDef
    cd StockDef
    npm install
    pip install -r pipeline/requirements.txt

    npm run fetch        # 한국 증시 일봉 10년치 수집 (30종목)
    npm run build:data   # 스테이지 윈도우 슬라이싱 + 아키타입 분류
    npm run seed         # DB 시드
    npm run dev          # 서버 :3000 + 웹 :5173 동시 기동

    → 브라우저에서 http://localhost:5173 접속

    ※ 차트 데이터(server/static/bars/)와 DB는 용량 문제로 저장소에
      포함하지 않았다. 위 3개 명령으로 로컬에서 생성된다.

■ 검증 명령

    npm run test              # 엔진·경제 유닛 테스트 (38개)
    npm run sim               # 봇 시뮬레이터 — 승률별 클리어율 곡선
    npx tsx scripts/e2e.ts    # 헤드리스 전체 여정 E2E (14개 체크, 약 5분)

5. 기술 구성
────────────────────────────────────────────────────────────────────────────────

  구조      npm workspaces 모노레포 4패키지
            shared/   전투 엔진 · 밸런스 상수 · 판정 수식 (서버·클라 공유)
            server/   Express + WebSocket + SQLite (판정은 서버 권위)
            web/      Vite + React + Canvas 2D
            pipeline/ Python (yfinance 수집 → 스테이지 데이터 빌드)

  규모      자체 코드 약 7,000줄 (외부 리그 런타임 2,700줄 별도)
            에셋 743개 · 요구사항 명세 90개 항목 (PRD 1,114줄)
            커밋 64개

  설계 원칙
    · 판정은 전부 서버 권위. 체결가·손익·승패 검증을 서버가 재현한다.
    · 전투 엔진은 렌더러와 완전히 분리돼 있어, 같은 엔진을 헤드리스
      봇 시뮬레이터로 돌려 밸런스를 정량 측정한다.
    · 밸런스 상수는 한 파일(balance.ts)에 모여 있고, 모든 변경은
      봇 시뮬레이터로 클리어율 곡선을 재측정한 뒤 반영한다.


────────────────────────────────────────────────────────────────────────────────
6. 데이터 출처 및 고지
────────────────────────────────────────────────────────────────────────────────

  · 차트는 실제 한국 증시 과거 일봉 데이터(yfinance)를 사용한다.
  · 종목명·기간은 스테이지 진행 중에는 완전히 가려지며, 클리어 후에만
    공개된다. 블라인드 상태에서는 섹터·시가총액 규모 태그만 노출된다.
  · 본 콘텐츠는 과거 데이터를 활용한 게임이며 투자 조언이 아니다.
    게임 내 손익 수식은 재미를 위해 변동성으로 정규화·증폭된 값으로,
    실제 투자 수익률과 무관하다.
